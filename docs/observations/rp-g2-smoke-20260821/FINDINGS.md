## 1. 冒烟两跑（DoD §2.8.3 要求 1 个主题型 + 1 个个股型）

### ① 主题型：「黄金会怎么走」 → [归档](run-gold-macro/)

| 看什么 | 结果 |
|---|---|
| 资料夹里的宏观那格 | **没有 fred 这一条**（`macro_payload` 只剩 `rss` / `wisburg`） |
| 整体质量标记 | `degraded`（宏观腿失败，**如实降级**，不阻塞其他源） |
| 引用清单 | 4 条，**一条 `REF#F-` 都没有** |

🔑 **对照改造前**：同样这句问题，以前 fred 会**成功**返回 `CPIAUCSL` = `332.813`，
拿到一个 `REF#F-00x` 编号进引用清单，被下游当证据 —— 而**日志里一个字都没有**。
现在这条腿明确空着，且产物里看得见它为什么空。

### ② 个股型（混合宏观）：「美联储加息对英伟达的影响」 → [归档](run-nvda-macro-mixed/)

| 看什么 | 结果 |
|---|---|
| 路由 | `fred: macro_safety_net` —— ✅ **宏观安全网照常开火** |
| fred 返回 | `FEDFUNDS` **6 期序列**：`3.64 → 3.64 → 3.64 → 3.63 → 3.63 → 3.63` |
| 整体质量标记 | `ok`（四个源全成功） |

🔑 **这一跑同时兑现了 G2 的停止条件**：「触到宏观安全网行为变化 → 先补测再继续」——
**未触发**，安全网行为逐字未变（关键词表一个键没删，就是为了这个）。

## 2. 真 API 逐条验证（不经 mock，直调数据源）

| 验收判据（写在设计 pass 里的原话） | 实测结果 |
|---|---|
| 「问通胀拿回的是**同比序列**而不是 `332.813`」 | ✅ `value=3.30386` · `unit=percent_change_year_over_year` · 6 期：`2.43 / 3.29 / 3.78 / 4.17 / 3.46 / 3.30` ⇒ **"连续三个月回落"这个结论现在拿得到了**（以前只取一期，整个丢掉） |
| 「**指标编号可由计划点名**」 | ✅ 点名 `CPIAUCSL` + 原值 + 3 期 → `332.813` · `unit=index_1982_1984_100`（**同一个序列、换取法、量纲标签跟着变** —— 这正是 G2 要的诚实性） |
| 「问贵金属/商品**不再静默落 CPI**」 | ✅ 抛错，且错误文本**点名**：「本源不再静默落回 CPI（backlog BR）」 |
| 「**搜索候选不得自动取第一条**」 | ✅ 返回列表 + 每条带最后有数日期：`PCU2122212122210(2017-12 停更)` / `IQ12260(2026-07)` / `NASDAQQGLDI(2026-08)` —— **一条金价都没有**，与 G0 双验证一致 |

> ⚠️ **第 4 行顺带再次坐实**：FRED 库里**没有现货金价**。所以「黄金」那条腿空着**是对的** ——
> 不是我们取数取砸了，是这个源本来就答不了这个问题。金价归行情源（G4 已让它认得 `GC=F`）。

## 3. 边界（如实标，别读大）

- **只跑了第 ① 段**：后八段没跑。G2 的改动不出这一段，但「下游读到 6 期序列会怎么写」**没有实证**
  —— 那要等 G7 全链跑。⇒ 本文件**不构成**"下游没问题"的证据。
- **`degraded` 是不是好事，取决于问的是什么**：问黄金时它是对的（该源答不了）；
  但如果哪天一个**真宏观**问题也 `degraded`，那是关键词表覆盖不全的老问题（**BR 没解决的那半**），
  不是本次改动造成的。两者在产物里长得一样，**区分只能靠看错误文本**。
- **子串误命中（`DEFECT-FRED-SUBSTRING`）本次没测也没修** —— 问「毛利率」仍会拿到联邦基金利率。
  那是另一个病（撞上了但撞错），归 G5。
