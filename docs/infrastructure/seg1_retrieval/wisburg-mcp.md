## 1. 两条最要紧的机制（读工具表之前先看这个）

### ① 检索词是**排序**，不是**过滤**

服务端原话：「**不传时按发布时间倒序返回最新内容；传入时按相关度排序**」。

⇒ 传了检索词**并不会把不相关的剔除**，只是把相关的排前面。**如果符合其他条件的内容不足一页，剩下的位置会被不相关内容填满。**

**这解释了一个实测现象**：只传「黄金」时 20 条几乎全对题；再加上近四天的时间窗后，**20 条里只剩 4 条与黄金有关**（其余是铜、锂、中国消费、澳洲贸易）。
**不是"时间窗稀释了相关性"，而是"那个窗里本来就没有 20 条黄金报告，于是拿别的补满"。**

⇒ **消费方必须自己按相关性筛结果**，不能假设"返回的都是对题的"。

### ② 「能不能拿到全文」要分三档，别一概而论

| 内容类型 | 拿得到什么 | 说明 |
|---|---|---|
| **五个报告库**（投行 / 企业 / 资管 / 公开文献 / 电话会） | ❌ 无原文，✅ **智堡自撰摘要** | 服务端明写：「只对外提供笔记摘要，**不提供报告原文或原文下载链接**；若摘要不足以回答问题，请**如实说明而不要臆测原文内容**」 |
| **智堡自己的研究文章** | ✅ **完整正文**（HTML 已转 markdown，含表格） | 自有内容，无版权限制 |
| **资讯流 / Mikko 日志** | ✅ **列表里就自带正文** | 资讯流每条带 markdown 正文（列表中截断至 300 字）；Mikko 日志本身短，列表直接给全文 |

⚠️ **所以"智堡取不到正文"这句话只对第一档成立。** 第二、三档是能拿全的，而且第三档**一次调用就够，不用二次请求**。

| 工具 | 装什么 | 要点 |
|---|---|---|
| `list-feed` | 投研资讯流（研报要点短条目） | ⭐ **每条自带正文**（截断 300 字）—— 问「最近发生了什么」**一次调用就够** |

| `list-images` | 金融数据图表 / 信息图 | 返回**可直接引用的图片直链**；⚠️ **不返回 ID，也没有对应详情工具** |

### 三个取详情的

| 工具 | 入参 | 返回 |
|---|---|---|
| `get-report-detail` | `id`（**整数**，必填）· `category`（可选，`ib`/`company`/`am`/`archive`/`ec`，默认 `ib`） | 标题、发布时间、**智堡自撰摘要**（markdown） |
| `get-article-detail` | `id`（整数） | **完整正文**（markdown，含表格） |
| `get-mikko-log-detail` | `id`（整数） | 正文 + **配图直链**。⚠️ 列表已给全文，**只在需要配图时才调** |

## 3. 通用参数（所有 `list-*` 工具共用这五个）

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `query` | 字符串 | 无 | 检索关键词，**支持中文**。⚠️ **是排序不是过滤**（见 §1①）。不传 = 按发布时间倒序 |
| `first` | 整数 | **20** | 每页条数，**范围 1–100**。⚠️ 本项目今天用默认值，**上限其实是 100** |
| `after` | 字符串 | 无 | 分页游标。把上次返回里 `Next cursor` 的值**原样填入**；首次不传 |
| `startTime` | 字符串 | 无 | 起始时间。**推荐带时区偏移**（`2026-08-01T00:00:00+08:00`） |
| `endTime` | 字符串 | 无 | 同上 |

⚠️ **时区坑（服务端自己写明的）**：只传纯日期 `2026-08-01` 会**按 UTC 零点解析**，等于**北京时间当天早上 8 点** —— 想要"整个 8 月 1 日"必须带时区偏移，否则会漏掉当天凌晨的内容。

## 4. 已实测的坑

| 坑 | 说明 |
|---|---|
| **编号必须传整数** | `get-report-detail` 传字符串 `"100085"` 会被参数校验拒绝（探针首跑就踩了）。✅ **2026-08-20 复测坐实**，并补上**拒绝的形态**：不是抛异常，而是 `isError: true` + 内容里一段 `MCP error -32602: Input validation error ... expected "number", received "string"` ⇒ **调用方收不到任何异常**（见下方 🔴 行） |

| **检索词 + 时间窗叠加会掺进不相关内容** | 机制见 §1①。要时效性请自己在结果里按日期筛 |
| **摘要是第三方转述** | 引用时定性要写"某机构报告的**智堡摘要**"，**不能说成该机构原文** |
